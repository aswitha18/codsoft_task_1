# 📝 To-Do List Application

## 📌 Description
The To-Do List Application is a simple command-line project developed using Python. It helps users manage their daily tasks by allowing them to add, view, update, and delete tasks through a menu-driven interface.

## ✨ Features
- Add a new task
- View all tasks
- Update an existing task
- Delete a task
- Menu-driven interface
- Easy to us

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code (VS Code)
